# Security Policy

Kestrel Ridge Health (KRH) publishes this repository as the public marketing site (static files served by GitHub Pages). Use this policy to report a vulnerability in the site or this repository.

## Reporting a vulnerability

Report vulnerabilities privately, using either channel:

- [GitHub private vulnerability reporting](https://github.com/thomashillwagenberg-spec/kestrel-ridge-site/security/advisories/new) for this repository
- The contact form at <https://kestrelridgehealth.com/contact/>

Do not open a public GitHub issue, and do not put vulnerability details in a public pull request, commit, or other public channel.

We will acknowledge a report within 5 business days.

Never include patient data or protected health information (PHI) in a report, attachment, or follow-up. Include only the technical details needed to understand and reproduce the issue.

## Patient data

KRH is not HIPAA certified and does not accept, store, or process patient data. This repository and the public marketing site are not a place for clinical records or other PHI.
